# chatbot-demo — пример использования @mirta/chatbot

Это **полноценный проект Mirta**, демонстрирующий работу Telegram-бота в реальном окружении.

Он помогает:
- Проверить, как бот принимает команды и отправляет сообщения
- Протестировать политики доступа
- Отладить кнопки, меню и колбэки
- Изучить best practices по настройке

Примеры реализованы в:
- [src/wb-rules-modules/bot-telegram.ts](https://github.com/wb-mirta/chatbot/blob/latest/projects/chatbot-demo/src/wb-rules-modules/bot-telegram.ts) — настройка бота и политик
- [src/wb-rules/bot-usage.ts](https://github.com/wb-mirta/chatbot/blob/latest/projects/chatbot-demo/src/wb-rules/bot-usage.ts) — обработка команд и колбэков

> 💡 Вы можете собрать и задеплоить этот проект на свой контроллер Wiren Board — он полностью рабочий.

## ⚠️ Важно

Перед деплоем сделайте резервную копию существующих правил

## Отладка бота на тестовом контроллере

**Клонируйте репозиторий** (если ещё не сделали):

```bash
git clone https://github.com/wb-mirta/chatbot.git
cd chatbot
```
> Остальные консольные команды нужно выполнять в корне репозитория.

**Установите зависимости**:

```bash
pnpm install
```

**Соберите проект**:

```bash
pnpm build
```

**Создайте файл `.env.local` в корне проекта**:

```env
APP_TELEGRAM_TOKEN=ваш_токен_от_BotFather
APP_TELEGRAM_USER=ваш_telegram_id
```
   
**Настройте подключение к контроллеру**:

Отредактируйте `mirta.config.json`:
- Укажите IP-адрес контроллера
- При необходимости — настройки SSH, PKCS#11, WSL

**Задеплойте на контроллер**:

```bash
pnpm --filter ./projects/chatbot-demo run wb:deploy
```
При первом запуске деплоя добавьте флаг `--dry-run`, чтобы оценить последствия

## 🧪 Что будет работать?

После деплоя:
- Бот начнёт принимать команды
- Реагировать на `/start` с клавиатурой
- Обрабатывать нажатия кнопок (например, "Say Hello!")
- Отправлять сообщения обратно

## 🔧 Хотите проверить изменения в боте?

Измените код в `packages/chatbot`, пересоберите проект и задеплойте снова — это ваш **интеграционный стенд** для тестирования.
